# CFG Platform Repository Templates

These files are prepared for the independent TrackQMS and TrackQMS-Kanban Connector repositories.
They are templates, not installed Kanban application code.

Apply `track_qms/AGENTS.md` to the root of the existing TrackQMS repository after that repository is
attached locally. Apply the connector template when creating the independent connector repository.
Preserve and merge any more specific existing repository rules rather than overwriting them.
